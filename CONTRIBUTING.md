# CONTRIBUTING

Thank you for contributing to OI Cards.

---

# Workflow

1. Read documentation.
2. Create a new branch.
3. Implement one task.
4. Test changes.
5. Update documentation.
6. Create commit.
7. Open Pull Request.

---

# Branch Naming

feature/...

fix/...

refactor/...

docs/...

---

# Commit Examples

feat: add customer CRUD

fix: resolve slug generation

refactor: normalize social links

docs: update database specification

---

# Pull Requests

Every PR must include

- Summary
- Files Changed
- Screenshots (if UI)
- Testing Notes

---

# Code Review Checklist

- Build passes.
- TypeScript passes.
- No duplicated code.
- Documentation updated.
- No breaking changes.

---

# AI Contributions

If an AI agent modifies code

It must

- Read all files inside docs/.
- Follow AGENTS.md.
- Work on one task only.
- Generate TASK_REPORT.md.
- Wait for approval before continuing.
