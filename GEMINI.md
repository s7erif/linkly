# Tappy

One Tap. Endless Connections.

---

# Project Vision

Tappy is a premium digital identity platform built around NFC technology.

The goal is not simply to create another Link-in-Bio website.

We are building the Apple of Digital Business Cards.

Everything should feel:

- Premium
- Minimal
- Beautiful
- Fast
- Effortless

Every screen should communicate trust, elegance and simplicity.

---

# Core Principles

Less, but better.

Whitespace is a feature.

Motion should guide attention.

Animation should never distract.

Everything should feel intentional.

Every component should feel handcrafted.

---

# Design Language

Inspired by:

- Apple
- Linear
- Arc Browser
- Raycast
- Nothing
- Stripe
- Vercel
- Framer

DO NOT create generic SaaS UI.

DO NOT create template-looking components.

DO NOT overuse gradients.

DO NOT overuse colors.

The interface should feel calm.

---

# Design Style

Premium Minimalism

Liquid Glass

Glassmorphism (subtle)

Editorial Typography

Large whitespace

Soft shadows

Soft gradients

Rounded corners

Elegant transitions

No visual clutter.

---

# Colors

Use neutral colors.

Black

White

Gray

Soft blue accents

Soft cyan glow

Very limited accent colors.

Everything should work in Dark Mode first.

---

# Typography

Large headlines.

Small supporting text.

Comfortable line-height.

Editorial spacing.

Readable hierarchy.

---

# Motion

Motion is part of the product.

Every animation should have purpose.

Prefer:

- Fade
- Blur
- Scale
- Opacity
- Translate
- Stagger
- Soft parallax
- Floating objects

Avoid:

- Bounce
- Spin
- Flashing
- Excessive movement

Always use premium easing.

Animations should feel similar to Apple product pages.

Respect prefers-reduced-motion.

---

# Components

Components must be reusable.

Never duplicate UI.

Create clean architecture.

Example:

components/

landing/

ui/

shared/

workspace/

---

# Code Quality

Use:

Next.js App Router

TypeScript

TailwindCSS

Framer Motion

Lucide Icons

Never use inline styles.

Never create massive components.

Split components logically.

Avoid prop drilling.

Use server components whenever possible.

---

# Responsiveness

Desktop first.

Tablet.

Mobile.

Animations should work across all devices.

---

# Performance

Optimize images.

Lazy load heavy assets.

Avoid unnecessary rerenders.

Keep animations at 60 FPS.

# UI Philosophy

Everything should feel expensive.

Never make UI noisy.

Every pixel matters.

Every animation matters.

Every spacing decision matters.

---

# When implementing UI

Always think like a Senior Product Designer.

Not just a Frontend Engineer.

If there are multiple possible implementations:

Choose the one that feels more premium.

Never choose the easiest solution.

Choose the most polished solution.

---

# Business Logic

Do NOT redesign business logic.

Do NOT redesign architecture.

Do NOT change routes.

Do NOT modify repositories.

Focus only on frontend, UI, UX and animations unless explicitly instructed otherwise.
