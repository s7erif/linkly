# Codex Rules

Before making ANY UI change

Read all Design System documents.

Never reinterpret the design language.

Never replace the design language.

Improve it only.

Never convert Premium Minimal into Flat Design.

Never convert Operational Dashboard into Analytics Dashboard.

Reuse components.

Preserve consistency.

If uncertain,

prefer the existing implementation over inventing a new one.

Design consistency is more important than originality.
