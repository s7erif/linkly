# Color System

## Primary Background

Dark neutral.

## Secondary Background

Slightly lighter than the primary background.

## Surface

Solid.

No colorful backgrounds.

## Elevated Surface

Slightly brighter.

Soft shadow.

## Border

Neutral gray.

Never dominant.

## Accent

Only ONE accent color.

Allowed only for

- Primary button
- Active navigation
- Keyboard focus
- Selected chips
- Active tabs
- Links

Never use the accent for decorative cards.

Never create colorful KPI cards.

Never create rainbow charts.
