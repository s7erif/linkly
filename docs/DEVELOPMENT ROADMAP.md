✔ Never duplicate code

✔ Feature-based architecture

✔ Services contain business logic

✔ Components contain UI only

✔ One rendering engine

✔ Database first

✔ Mobile first

✔ API first

✔ Test before merge

✔ Document every feature

- Database implemented

- UI completed
